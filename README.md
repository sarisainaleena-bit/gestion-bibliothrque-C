# Gestion Bibliotheque en C

Projet de gestion de bibliotheque en langage C avec liste chainee.

## Fonctionnalites
- Ajouter un livre (ID, Titre, Auteur)
- Afficher la liste
- Supprimer un livre
- Utilise malloc / free

## Concepts utilises
- struct + pointeur suivant
- Liste simplement chainee
- Allocation dynamique

## Compilation
gcc main.c -o bibliotheque
./bibliotheque
